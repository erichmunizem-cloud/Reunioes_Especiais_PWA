GitHub Pages:
1. Envie todo o conteúdo desta pasta para a raiz do repositório.
2. Settings > Pages > Deploy from a branch.
3. Selecione main e /(root).

Uso local:
O conteúdo principal também abre por file:// porque os dados foram incorporados em data.js. Para instalar como PWA e usar cache offline, utilize HTTP/HTTPS.
Exemplo: python -m http.server 8080

Observação de fidelidade:
O texto bibliográfico em espanhol foi preservado como já estava digitalizado no pacote de origem. Como se trata de reconhecimento de texto, podem existir erros de OCR; a reconstrução não corrige silenciosamente palavras ou referências duvidosas.
